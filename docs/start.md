# Getting started with VSCP Works+

This is the official documentation for VSCP Works, software that is part of the VSCP & Friends package. VSCP is an IoT framework built mainly for resource-limited devices.

Besides this document, you can read all about VSCP and download its components from [the VSCP site](https://www.vscp.org "The VSCP site").

VSCP Works runs on Windows, Linux and macOS. It is a [Qt-based application](https://www.qt.io/) used to configure and manage VSCP nodes and to update their firmware. It is a rewrite of the old VSCP Works, which was based on wxWidgets. The new version is much more flexible, easier to use and has many more features.

VSCP Works is licensed under the MIT License, so it can be used freely in both open-source and closed-source projects.

VSCP Works can be [downloaded here](https://github.com/grodansparadis/vscp-works-qt) as source code or as binaries. Select the latest release and download the binary for your platform, or download the source and build it yourself.
