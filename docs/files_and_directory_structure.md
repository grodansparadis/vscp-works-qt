# Linux

 | File(s) | Path |
 | ------ | ---- |
 | Configuration file | .config/VSCP/vscp-works-qt.json |
 | General program folder. Holds databases, etc. | .local/share/VSCP/vscp-works-qt/ |
 | Default folder for saved received events. | .local/share/VSCP/vscp-works-qt/rx-sets/ |
 | Default folder for saved transmit events. | .local/share/VSCP/vscp-works-qt/tx-sets/ |
 | Default folder for logs. | .local/share/VSCP/vscp-works-qt/logs/ |
 | Default folder for automatically saved transmission sets. | .local/share/VSCP/vscp-works-qt/logs/ |
 | Default folder for exported sessions. | .local/share/VSCP/vscp-works-qt/sessions/ |
 | Autosaved/autoloaded session TX rows (`txevents_<connection uuid>.xml`). | .local/share/VSCP/vscp-works-qt/cache/ |
 | Database with known GUIDs and sensors. | .local/share/VSCP/vscp-works-qt/vscpworks.sqlite3 |
