# Setting up the system

## VSCP Works setup instructions

1. **Download the installer**
  - Go to the [VSCP Works GitHub Releases](https://github.com/grodansparadis/vscp-works-qt/releases) page.
  - Download the latest installer for your operating system.

2. **Install the application**
  - Run the installer you downloaded.
  - Follow the on-screen instructions to complete the installation.

3. **Launch VSCP Works**
  - Start the application from your list of installed programs.
  - Check that the application starts without errors.

4. **Configure the initial settings**
  - Select `Edit` > `Settings...`.
  - Set your preferences, such as logging options and how data is displayed. See [settings](settings.md).

5. **Connect to a VSCP daemon**
  - Select `File` > `New connection...` and choose the connection type, for example tcp/ip.
  - Enter the details of your VSCP daemon, such as host address, port and credentials.
  - Use `Test connection` in the dialog to check the settings.

6. **Verify the connection**
  - Right-click the new connection and select `Session` to open a session window.
  - Connect, and check that events are received. You can also send a test event.

7. **Explore the features**
  - Get to know the features and tools available in VSCP Works.
  - See the [VSCP Works documentation](https://grodansparadis.github.io/vscp-works-qt/#/) for detailed guides.

8. **Keep the application up to date**
  - Check for updates regularly so you have the latest features and security fixes.
  - Use `Help` > `Check for updates...` to see if a new version is available.

After these steps, VSCP Works is set up and ready to use.
