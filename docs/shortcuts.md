# Shortcut keys

## Main window

| Key | Function |
| --- | -------- |
| F1 | Open help for connections |
| Ctrl + Q | Exit (Linux/macOS) |

## Session window

| Key | Function |
| --- | -------- |
| F1 | Open help |
| Ctrl + O | Connect/disconnect |
| Ctrl + N | Clear RX list |
| Ctrl + X | Close window |
| Alt + 2 | Clear TX list |
| Alt + C | Toggle RX class mark |
| Alt + M | Toggle RX row mark |
| Alt + T | Toggle RX type mark |
| Alt + U | Un-select all RX rows |

See [session window](session_window.md) for all functions.

## Node scan window

| Key | Function |
| --- | -------- |
| F1 | Open help |
| Ctrl + C | Connect |
| Ctrl + F | Scan |
| Ctrl + L | Load MDF for selected node |
| Ctrl + A | Load MDF for all nodes |
| Ctrl + 1 | Open session window |
| Ctrl + 2 | Open configuration window |
| Ctrl + X | Quit |

## Configuration window

See [configuration window](config_window.md).

## MDF editor

| Key | Function |
| --- | -------- |
| F1 | Open help |
| Ctrl + N | New MDF |
| Ctrl + O | Open MDF |
| Ctrl + S | Save MDF |
| Ctrl + E | Edit item |
| Ctrl + D | Delete item |
| Ctrl + X | Quit |

--- | -------- |
| Ctrl + A | Send TX event(s) |
| Ctrl + C | Copy RX row to clipboard |
| Ctrl + M | Clear TX list |
| Ctrl + N | Clear RX list |
| Ctrl + T | Copy TX row to clipboard |

### ALT key bindings

| Key | Function |
| --- | -------- |
| Alt + C | Mark RX class |
| Alt + E | Open up the edit menu |
| Alt + F | Open up the file menu |
| Alt + H | Open up the host menu |
| Alt + M | Toggle selected RX row(s) |
| Alt + P | Open up the VSCP menu |
| Alt + S | Open up the settings menu |
| Alt + T | Open up the tools menu |
| Alt + Y | Mark RX Type |
| Alt + U | Un-select all RX rows |
| Alt + V | Open up the View menu |

## Dialogs

| Key | Function |
| --- | -------- |
| F1 | Open the manual section for the dialog (same as its `Help` button) |
